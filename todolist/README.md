# 📝 To-Do List Project

## Description
This is a simple Python-based To-Do List application. It helps users manage their daily tasks by allowing them to add new tasks, view all tasks, and exit the program. The project is built using basic Python concepts like loops, lists, and conditional statements.

## Features
- Add new tasks
- View all added tasks
- Display task numbering
- Handle empty task list
- Simple menu-driven interface

## How to Run
1. Install Python on your system
2. Open VS Code or terminal
3. Run the program using:
   python main.py

## Example Menu
1. Add Task
2. View Tasks
3. Exit

## Output Example
Your Tasks:
1. Buy groceries
2. Complete assignment
